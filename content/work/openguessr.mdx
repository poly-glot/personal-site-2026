<Chapter label="The challenge" title="Play with friends on places nobody has seen." lede="A geography game only works if the places are a real puzzle and the scores feel fair. A famous square is guessed in a second, a recycled list soon becomes familiar, and right-or-wrong scoring treats a near miss like a wild guess. The game also had to start from a shared link, with no accounts.">
<Rows>
  <Row title="Start from a link">A name and a shared link are enough. The host runs the room, and if the host leaves, the game carries on.</Row>
  <Row title="Places nobody knows">Ordinary streets in small towns, not landmarks, and a fresh supply every day so the list never becomes familiar.</Row>
  <Row title="Score how close">A guess in the next town should beat a guess on the wrong continent. Points fall smoothly with distance.</Row>
  <Row title="Keep it honest">The server scores every guess and holds the answer until everyone has played the round.</Row>
</Rows>

<Chapter label="Picking places" title="How to pick a place nobody can guess." lede="Every day a scheduled function asks Gemini for 50 new places, and Google decides which ones are real. A place reaches a game only after passing every step.">
<LocationPipeline />
<Facts>
  <Fact k="Ask">Gemini 2.5 Flash, once a day, for 50 streets: at least four of six world regions, no country more than twice, named roads in small towns and side streets, never near a top-100 landmark.</Fact>
  <Fact k="Check">Each suggestion goes to Google's Street View metadata API. Only places with a real panorama within 1 km survive, moved to where the panorama actually is.</Fact>
  <Fact k="Thin out">Places within about a kilometre of one already in the pool are dropped. The pool stops at 500.</Fact>
  <Fact k="Deal">Each new game shuffles the pool and takes five. If the pool is ever short, a list of about 100 places across six continents keeps the game working.</Fact>
  <Fact k="Hide">The panorama opens facing north, with the address, road labels and movement arrows switched off. The country stays on the server until the round is revealed.</Fact>
</Facts>
</Chapter>

<Chapter label="Scoring" title="Score how close you were." lede="The server measures the distance between the pin and the real place along the curve of the Earth, then turns it into points: 5,000 × e to the power of minus the distance over 2,000 km. <List>
  <Item title="Distance on a sphere.">The haversine formula gives the great-circle distance, so a guess across the Pacific is measured the right way round.</Item>
  <Item title="A curve, not a cliff.">The right region still earns most of the points. The other side of the world earns almost none.</Item>
  <Item title="Scored on the server.">The browser sends only the pin. A function works out the score and adds it to the total in one transaction.</Item>
  <Item title="No guess, no points.">If the minute runs out, the round scores zero.</Item>
</List>

<Chapter label="Playing live" title="Everyone sees the same round at once." lede="The game state lives in Firebase Realtime Database, so every change reaches every player as it happens.">
<List>
  <Item title="Presence.">When a player's connection drops, the database marks them offline, and the round no longer waits for them.</Item>
  <Item title="The host can leave.">If the host disappears, the highest-scoring player still online takes over. Players can also ask the room to vote them in.</Item>
  <Item title="Reveal when ready.">The answer appears the moment every online player has guessed, without waiting out the clock.</Item>
  <Item title="No accounts.">A name gets a signed token for this game only. Old rooms are deleted after 24 hours.</Item>
</List>
</Chapter>

<Chapter label="The limits" title="Where it stops today." lede="Each limit is a known trade, with the next step already named.">
<List>
  <Item title="The coordinates reach the browser.">The panorama needs them, so a player with the developer tools open can read the answer. The country is already locked away, and a locked place for coordinates exists with tests. The next step is serving the panorama by an opaque ID.</Item>
  <Item title="The pool follows the prompt.">Gemini spreads places by the rules it is given, which is varied but not truly random. A random sample of Street View coverage would be fairer and costlier.</Item>
</List>
</Chapter>

<Chapter label="The learning" title="What carried forward." lede="The figures below come from the code and can be checked in the repository.">
<Split>
<List>
  <Item title="Let AI suggest, let real data decide.">Gemini is good at ordinary places, and wrong often enough that every one is checked against Street View before it counts.</Item>
  <Item title="Score on a curve.">A near miss in the right region earns most of the points, so the score rewards knowing the world, not luck with one country.</Item>
  <Item title="Choose the database for what it does.">Realtime Database's presence and connection signals do the multiplayer work that would take extra services elsewhere.</Item>
