<Chapter label="The brand" title="Dignity, respect and choice, in colour." lede="The company's strapline was Dignity, Respect, Choice. Rather than leave it in the logo, the design gave each value a colour and used those colours across the whole site.">
<Facts>
  <Fact k="Dignity">Bright blue, the main colour. It fills the panel at the top of most pages and the dignity heading.</Fact>
  <Fact k="Respect">Black, for the respect heading.</Fact>
  <Fact k="Choice">Pink. Wherever the copy says CHOICE, the word is set in pink, so the promise stands out on every page that makes it.</Fact>
  <Fact k="Ethos">The ethos is six lines whose first letters spell PERSON, from Providing to Never tiring. Each first letter is set large, like the start of a chapter.</Fact>
  <Fact k="Type">Open Sans for headings and Droid Serif for reading, both from Google Fonts.</Fact>
</Facts>
</Chapter>

<Chapter label="Responsive" title="One site for every screen." lede="In 2014 responsive design was still new, and many small business sites served the desktop page to phones or sent them to a separate mobile site. This site used one set of pages that rearranged itself for the screen.">
<Figures>
  <Figure src="/img/work/ech-uk/philosophy.webp" phone="/img/work/ech-uk/philosophy-phone.webp" phoneAlt="The philosophy page on a phone, with the Dignity and Respect blocks stacked." w={1600} h={1000} alt="The philosophy page on a desktop, with three values side by side." title="Columns that stack">On a desktop the three values sit side by side. On a phone they stack in order.</Figure>
  <Figure src="/img/work/ech-uk/home.webp" phone="/img/work/ech-uk/menu-phone.webp" phoneAlt="The phone menu open, listing the seven pages on a dark blue panel." w={1600} h={1000} alt="The home page on a desktop with the full menu across the top." title="A menu button">The menu across the top becomes a Menu button and a full list on phones.</Figure>
</Figures>
<Facts>
  <Fact k="Grid">A fluid 12-column grid in percentages, up to 1,100 pixels wide, so the layout stretches with the window.</Fact>
  <Fact k="Breakpoints">The layout changes at 768 pixels for phones, again in between for tablets, and at 1,400 pixels the text gets larger for big screens.</Fact>
  <Fact k="Phones">A fixed header with a Menu button, run by a few lines of plain JavaScript with no library. The phone number is a link, so a family can tap to call.</Fact>
  <Fact k="Older browsers">A small script taught Internet Explorer 8 and earlier the new HTML5 elements, so the same pages worked on office computers too.</Fact>
  <Fact k="Weight">Photos were resized to fit the page, and a few small images were written straight into the stylesheet to save requests.</Fact>
</Facts>

<Chapter label="Looking back" title="What aged, and what didn't." lede="Seen from today, most of the site holds up. A few choices of the time don't.">
<List>
  <Item title="Zoom was switched off.">The page told phones not to let people zoom in, which was common in 2014 to keep layouts steady. Today it's an accessibility failure, and it matters more on a site for people with disabilities and their families.</Item>
  <Item title="Cookie notices became law.">From May 2012, UK websites had to tell visitors about the cookies they used. The site has a cookie policy that lists each Google Analytics cookie by name and what it does.</Item>
  <Item title="Responsive design won.">One set of pages for every screen is now simply how websites are built.</Item>
</List>
</Chapter>
