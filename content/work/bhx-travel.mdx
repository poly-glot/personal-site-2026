<Chapter label="Editing" title="The owners edit the site themselves." lede="Pages, the header and the footer are all content in Builder.io, a visual editor. The owners drag in blocks, change the words and publish. They never touch code and they never wait for a deploy.">
<QuoteFlow />
<Facts>
  <Fact k="Own blocks">Eight of the site's own components are registered in the editor: navigation, icons, contact details, social links, headings, lists, buttons and the quote form. Pages are built from the brand's pieces, so the design stays intact.</Fact>
  <Fact k="Live fast">Pages are static and Next.js rebuilds a page within 15 seconds of a change. A new page made in the editor goes live without a deploy.</Fact>
  <Fact k="Preview">The editor shows the real site in a frame. The site only allows Builder.io to frame it, so no other site can.</Fact>
  <Fact k="Privacy">The editor adds a tracking pixel to every page. The site strips it out before the page is built.</Fact>
</Facts>
</Chapter>

<List>
  <Item title="One way or return.">Picking one way switches the return date and time off, so nobody fills in fields that don't apply.</Item>
  <Item title="The reason for the trip.">15 choices, from airport to wedding to football, help the owners plan the right vehicle for the trip.</Item>
  <Item title="Checked on the server.">Every field is checked with Zod before anything is sent, and a problem comes back as a plain message on the form.</Item>
  <Item title="Easy to sort.">The email subject names the journey type, the pickup and the drop-off, so the owners can see each enquiry at a glance in their inbox.</Item>
  <Item title="Terms first.">The send button stays off until the booking terms are ticked.</Item>
</List>

<Chapter label="Engineering" title="Small, fast and easy to hand over." lede="The site is a small Next.js app. Anyone who knows React can pick it up.">
<Facts>
  <Fact k="Hosting">Vercel. Every push to the main branch deploys, and pages are served as static files from Vercel's cache.</Fact>
  <Fact k="Backup">Every Friday a GitHub Action exports all the Builder.io content and keeps it for 90 days. A new developer can import it into their own free space and start working.</Fact>
  <Fact k="Icons">Service icons are SVG files turned into React components with one command, so adding a service icon needs no design tool.</Fact>
  <Fact k="Tests">Jest and Testing Library cover the navigation and the quote form.</Fact>
</Facts>
</Chapter>

<Chapter label="The limits" title="Where it stops." lede="Each limit was a choice that suited a small firm.">
<List>
  <Item title="No online booking.">The site takes enquiries, not payments. Prices depend on the route, the day and the vehicle, so the owners quote each job themselves.</Item>
  <Item title="Content in a hosted editor.">The pages live in Builder.io. The weekly backup means the content can be moved if the service ever changes.</Item>
</List>
</Chapter>
